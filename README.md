# From this Earth

Per clonare la repository
Aprire Github desktop > File > Clone repository > QuantumDuck_GameJam

Inizializzare git lfs cliccando initialize 

Fare sempre un Fetch prima di inziare ad aggiungere cose e in caso fare il Pull se lo richiede

Controllare di essere nel branch giusto (Tech, Art o Design)
Per cambiare branch: Current branch > nome_del_branch

Per committare bisogna dare un titolo al commit e cliccare Commit to nome_del_branch
NON committare mai il file .umap salvo essere sicuri di essere i soli ad averla modificata

Per mergare un branch sul main:
Spostarsi sul main > Choose a branch to merge into main > selezionare il branch da mergiare > create a merge commit

Per pushare sulla repo online cliccare su Push origin

Se il vostro branch ha cose in meno rispetto al main bisogna fare un rebase
Avendo il vostro branch selezionato > Branch > Rebase current branch... > main
